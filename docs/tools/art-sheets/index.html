A tool by MLow

Art Sheets

Paint with spreadsheet cells. Drop in an image and it is repainted as a cell painting: broad colour regions, directional brushwork and a few drawn contours. Keep it as an Excel workbook, a vector SVG and a PNG.

Runs in your browser. Your images never leave this device.

Cell detail is the number of cells along the long edge.

Each stage is its own editable sheet in the workbook.

Add an image to begin.

Three files per image. The XLSX is a real Excel workbook where every cell is a painted spreadsheet cell. It has three sheets: Painting, Underpainting and Brushwork. Edit any cell colour by hand. It opens in Excel, Numbers, Google Sheets and LibreOffice. In Numbers, set zoom to 25% to see more of it. The SVG is true vector cell geometry, sharp at any size. The PNG is ready to share or print, at 1, 2 or 4 pixels per cell. The ZIP holds a folder per image with all three. This is the browser version of MLow's Mac app. See the source.
