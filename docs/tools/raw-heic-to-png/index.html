RAW + HEIC to PNG

Drop camera RAW files or iPhone photos. Each one comes back as an upright, full resolution PNG with the same name.

Runs in your browser. Your files never upload.
Waiting for photos.

What happens to your photo. RAW files go through LibRaw, the open source RAW engine, compiled to WebAssembly (about 1.5 MB, loaded the first time you drop a RAW). It demosaics the sensor data with the white balance and colour matrix your camera recorded, turns the picture upright, and gives an 8 bit sRGB PNG at full sensor size. If LibRaw cannot read a file, the tool uses the largest JPEG preview the camera stored inside the RAW and says so on the result. HEIC works as in HEIC to PNG: Safari reads it itself, other browsers load libheif. The desktop version used macOS Quick Look, because it applies the rotation and the system RAW colour pipeline where command line decoders do not. Colours from LibRaw can differ a little from Apple Photos.
