      Conservative, rule based substitutions only. It does not rewrite meaning, and it does not judge authorship.

      What changes. Every export is a new file named name-finished. Stills come out as PNG, animations as GIF and video as MP4 (H.264 with AAC audio) unless you pick a format. Re-encoding in the browser drops all embedded metadata: EXIF, GPS, camera and software tags, XMP and C2PA manifests. Clearframe adds back only a small mvibe eye and a one line “Made with Clearframe” note, like every mvibe tool.

      Repair, grain and dither. Repair boxes rebuild pixels from the ring around them, the same idea as FFmpeg's delogo filter: great on skies, walls and gradients, softer on busy detail, and it does not track moving objects. Grain is seeded, so the same seed always gives the same texture. The 16 dithers are a port of the desktop app's engine with fixed palettes, so colours hold still across an animation.

      Limits. Video is read frame by frame at the frame rate you pick, which is exact but takes a while on long clips; trim first. MP4 needs WebCodecs (Chrome, Edge, Safari 17+). HDR clips come out as standard range. GIF has no partial transparency. Very large stills can hit the browser's canvas limit (about 16k px on a side, less on phones).

      Desktop app. Clearframe is also a native macOS app with an FFmpeg engine, HDR tone mapping and camera RAW import. The source is in tools/clearframe.
