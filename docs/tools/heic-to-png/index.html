HEIC to PNG

Drop iPhone photos. Each one comes back as an upright, full resolution PNG with the same name.

Runs in your browser. Your files never upload.
Waiting for photos.

What happens to your photo. Safari reads HEIC itself. Other browsers load libheif, a WebAssembly HEIC decoder, the first time you drop a photo (about 3 MB, once). The picture is turned upright from the rotation stored in the file, kept at its full size, and saved as a lossless PNG. The desktop version of this tool used macOS Quick Look for the same reason: the usual command line decoders ignore the rotation flag, so portrait shots came out sideways. Very large photos, such as 48 MP shots, can pass the canvas size limit of Safari on iPhone.
