MP4 to GIF max 50MB

Drop a video and get the best GIF that fits under the limit. Drop a few images instead and they become one slideshow that fits too.

Runs in your browser. Your files never upload.
Decimal megabytes. Each GIF aims 3% under it to be safe.
Waiting for files.

  


  


  

    How it fits. The tool first tries the max quality GIF. If that is too big it steps down a ladder, keeping full size as long as it can:
    error diffusion dither, then ordered dither, then fewer colours (256 down to 96) and fewer frames (20 fps down to 11).
    If it is still too big, it shrinks the picture in steps from 85% down to 22% until it fits. The log shows each try.
    Every GIF has a palette built from the whole clip and stores only the part of each frame that changed. Images become one slideshow, 0.6 seconds each, upright, cropped to the first image's shape.
    Your browser decodes the video, so iPhone MOV files (HEVC) open in Safari and in Chrome on a Mac, but often not in Firefox or on Windows.
